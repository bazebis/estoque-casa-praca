      Sobre o app
      
                
        
                    
      • Estoque Casa da Praça
        • 
                    
      • Este app está em fase de piloto para contagem simples por áreas macro.
        • 
                    
      • Os dados ficam salvos localmente neste aparelho e navegador.
        • 
                    
      • O template JSON deve ser importado manualmente em cada aparelho.
        • 
                    
      • O Piloto rápido pode criar áreas macro e vínculos automaticamente; os módulos detalhados continuam disponíveis para ajustes manuais.
        • 
                    
      • A configuração de WhatsApp é opcional, local e não realiza envios automáticos.
        • 
                    
      • A contagem simples por área aceita múltiplas entradas e unidades textuais, sem conversão ou consolidação final.
        • 
                    
      • Ainda não existe integração com ERP ou API.
        • 
                    
      • Ainda não existe sincronização de dados entre aparelhos.
        • 
                    
      • Depois do primeiro carregamento ou instalação, o app pode abrir offline.
