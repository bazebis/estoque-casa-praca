    Importar catálogo CSV

      Templates de contagem
      
                
      Importe um template JSON para inspecionar grupos, áreas e itens. Isso não altera o catálogo nem inicia uma contagem.
      
                
                
                
      
                
      
                
      
            
      

            
      
                
                
      Locais físicos
      
                
      Organize cômodos, equipamentos e subdivisões. Estes locais ainda não alteram a contagem atual.

      Sobre o app
      
                
        
                    
      • Estoque Casa da Praça
        • 
                    
      • Este app está em fase de piloto para preparar a contagem por localização física.
        • 
                    
      • Os dados ficam salvos localmente neste aparelho e navegador.
        • 
                    
      • O template JSON deve ser importado manualmente em cada aparelho.
        • 
                    
      • Os locais físicos também são configurados manualmente.
        • 
                    
      • Ainda não existe integração com ERP ou API.
        • 
                    
      • Ainda não existe sincronização de dados entre aparelhos.
        • 
                    
      • Depois do primeiro carregamento ou instalação, o app pode abrir offline.
